# Vendor Performance Analysis | SQL, Python, Power BI

# Project Overview

Developed an end-to-end Vendor Performance Analysis project to evaluate vendor efficiency, purchasing trends, sales performance, inventory distribution, and profitability using SQL, Python, and Power BI.
The project focuses on analyzing vendor-level data to identify top-performing vendors, monitor purchase and sales contributions, evaluate gross profit, and support data-driven business decisions.

# Objectives
- Analyze vendor-wise sales and purchase performance.
- Identify top-performing and low-performing vendors.
- Evaluate gross profit and profit margins.
- Understand inventory turnover and stock distribution.
- Identify purchasing trends and business opportunities.
-Generate actionable insights through data analysis and visualization.
